DivisionType فقط «نوع» است، نه «عمق».
تا نسخه ۲ این دو تصادفاً یکی بودند چون شماره‌ها به ترتیب عمق بالا می‌رفتند. با اضافه شدن «منطقه شهری» که زیر شهر قرار می‌گیرد، این رابطه دیگر برقرار نیست. عمق را همیشه از زنجیره ParentCountryDivisionId بگیرید و شرط‌هایی مثل WHERE DivisionType < 5 را بازبینی کنید.

کدها

  • استان: دو رقمی، 00 تا 30
  • شهرستان: دو رقمی، در هر استان از 01
  • بخش: دو رقمی، در هر شهرستان از 01
  • دهستان: چهار رقمی، در هر بخش از 0001
  • شهر و منطقه شهری: چهار رقمی، در بازه 1001–1699 و 2000–2999
  • آبادی: شش رقمی

کد شهر و منطقه شهری و کد آبادی در کل کشور یکتا هستند. به همین دلیل می‌شود یک شهر یا آبادی را بین سال‌ها فقط با کدش دنبال کرد، حتی اگر شهرستان یا بخشش عوض شده باشد. کد بخش و دهستان یکتا نیست و برای آن‌ها به مسیر کامل نیاز دارید.

یکسان‌سازی کاراکترهای فارسی

فایل مرکز آمار حروف عربی و اعراب و کاراکترهای نامتعارف دارد. در تولید داده این‌ها اصلاح می‌شوند:

ازبهنمونه
ي ىیمرکزي ← مرکزی
كکكرمانشاه ← کرمانشاه
أ إ ة ۀا ا ه ه
اعراب و کشیدهحذفتهــران ← تهران
ارقام فارسی و عربیارقام لاتین
نیم‌فاصله بی‌اثرحذفاحمد‌آباد ← احمدآباد

نیم‌فاصله بعد از حرفی که به حرف بعد نمی‌چسبد (ا د ذ ر ز ژ و و …) هیچ اثر بصری ندارد و فقط مقایسه رشته‌ها را خراب می‌کند؛ این موارد حذف می‌شوند. نیم‌فاصله‌های معنادار مثل «اسلام‌شهر» دست‌نخورده می‌مانند.

نگارش خود مرکز آمار در برخی نام‌ها ناهماهنگ است («بندرعباس» و «بندر عباس» هر دو در فایل هستند). این موارد تغییر داده نشده‌اند، چون یکسان‌سازی‌شان حدس است نه اصلاح.

نمونه پرس‌وجو — شهرهای استان تهران

SELECT city.Name, county.Name AS County
FROM CountryDivisions city
JOIN CountryDivisions district ON district.Id = city.ParentCountryDivisionId
JOIN CountryDivisions county   ON county.Id   = district.ParentCountryDivisionId
JOIN CountryDivisions province ON province.Id = county.ParentCountryDivisionId
WHERE province.Name = 'تهران' AND city.DivisionType = 5
ORDER BY county.Name, city.Name;

فایل پورتابل روی PostgreSQL و SQLite واقعاً اجرا و تست شده است. برای MySQL و MariaDB فقط از دستورات استاندارد پشتیبانی‌شده استفاده شده.

ارتقاء دیتابیس از نسخه ۲ به نسخه ۳

شناسه‌ها بین سال‌ها ثابت نیستند، پس نمی‌شود جدول را ساده جایگزین کرد. پوشه migrations/1398-to-1404/ جدول نگاشت CountryDivisionIdMap را می‌سازد تا کلیدهای خارجی خودتان را به‌روز کنید.

# ۱) پشتیبان بگیرید
# ۲) جدول قدیمی حفظ و جدول نگاشت ساخته می‌شود
psql -d mydb -f migrations/1398-to-1404/upgrade.sql

# ۳) داده سال ۱۴۰۴ بارگذاری می‌شود
psql -d mydb -f data/1404/iran.sql

# ۴) بخش ۴ فایل upgrade.sql را روی جدول‌های خودتان اجرا کنید

جدول CountryDivisions_1398 دست‌نخورده باقی می‌ماند تا هر وقت خواستید مقایسه کنید. ستون MatchType می‌گوید نگاشت چقدر قابل اعتماد است:

MatchTypeتعدادمعنی
path۹۴۴۲۱مسیر کدها دست‌نخورده مانده؛ محل جابه‌جا نشده.
code۸۴۷۷مسیر عوض شده ولی کد یکتای ملی همان است — محل زیر شهرستان یا بخش تازه‌تشکیل‌شده‌ای رفته. چون کد شهر و آبادی در کل کشور یکتاست، این تطبیق هم قطعی است.
خالی۹۷۲معادلی در ۱۴۰۴ ندارد؛ حذف یا ادغام شده. NewId تهی است و تصمیمش با شماست.

۹۷۲ ردیف بی‌معادل شامل ۷۷۷ آبادی، ۱۵۶ دهستان، ۳۷ بخش و ۲ شهر است. برای بخش و دهستان کد یکتای ملی وجود ندارد، پس وقتی هم مسیر و هم نام عوض شده باشد تطبیق خودکار ممکن نیست.

پکیج npm

npm install @hameds/iran-country-divisions
import { load, DivisionType } from "@hameds/iran-country-divisions";

const ir = load();                       // جدیدترین سال موجود
const tehran = ir.search("تهران", { type: DivisionType.Province })[0];

ir.children(tehran.id);                  // شهرستان‌های تهران
ir.cities();                             // همه شهرها، بدون مناطق شهری
ir.urbanZones(cityId);                   // مناطق یک شهر
ir.villages(ruralDistrictId);            // آبادی‌ها؛ فقط اینجا lazy load می‌شوند
ir.path(id);                             // مسیر کامل از کشور تا محل

پکیج هیچ وابستگی ندارد و آبادی‌ها را فقط وقتی می‌خوانید بارگذاری می‌کند. جست‌وجو به ی و ک عربی، اعراب، فاصله و نیم‌فاصله حساس نیست.

GitHub Packages برای نصب توکن می‌خواهد.
رجیستری npm گیت‌هاب حتی برای پکیج عمومی هم به access token نیاز دارد. رجیستری اصلی این پکیج registry.npmjs.org است که بدون احراز هویت نصب می‌شود؛ نسخه روی GitHub Packages فقط آینه است.

اجرای محلی این صفحه

صفحه داده‌ها را با fetch می‌گیرد و مرورگرها این کار را روی file:// بلاک می‌کنند، پس باز کردن مستقیم فایل جواب نمی‌دهد. یک وب‌سرور ساده کافی است:

cd docs && python3 -m http.server 8000
# سپس http://localhost:8000

اگر پایتون ندارید:

npx serve docs
php -S localhost:8000 -t docs

برای میزبانی روی GitHub Pages در فورک خودتان: Settings ← Pages ← Deploy from a branch ← Branch: master /docs.

تعاریف

بر اساس سند استاندارد آدرس‌دهی مرکز آمار ایران که در source/geo_standard.pdf مخزن است.

  • استان: واحدی از تقسیمات کشوری با محدوده جغرافیایی معین که از به هم پیوستن چند شهرستان همجوار با توجه به موقعیت سیاسی، اجتماعی، فرهنگی، اقتصادی و طبیعی تشکیل می‌شود. کشور به ۳۱ استان تقسیم شده است.
  • شهرستان: واحدی از تقسیمات کشوری با محدوده جغرافیایی معین که از به هم پیوستن چند بخش همجوار که از نظر عوامل طبیعی، اجتماعی، اقتصادی، سیاسی و فرهنگی واحد متناسب و همگنی را به وجود آورده‌اند.
  • بخش: واحدی از تقسیمات کشوری با محدوده جغرافیایی معین که از به هم پیوستن چند دهستان همجوار مشتمل بر چندین مزرعه، مکان، روستا و احیاناً شهر تشکیل می‌شود.
  • دهستان: کوچک‌ترین واحد تقسیمات کشوری با محدوده جغرافیایی معین که از به هم پیوستن چند روستا، مکان و مزرعه همجوار تشکیل می‌شود و از لحاظ محیط طبیعی، فرهنگی، اقتصادی و اجتماعی همگن است.
  • شهر: محلی با حدود قانونی که در محدوده جغرافیایی بخش واقع شده و اکثریت ساکنان دائمی آن در مشاغل کسب، تجارت، صنعت، کشاورزی، خدمات و فعالیت‌های اداری اشتغال دارند، در زمینه خدمات شهری از خودکفایی نسبی برخوردار است و حداقل ده هزار نفر جمعیت دارد.
  • آبادی: محدوده‌ای واقع در یک دهستان با حدود ثبتی یا عرفی مستقل و خارج از محدوده شهرها یا آبادی دیگر، که به دلیل وجود فعالیت انسان در تمام یا بخشی از آن قابل تشخیص است و معمولاً نام خاصی دارد. می‌تواند یک ده، یک مزرعه، یک مکان یا یک معدن باشد.
  • منطقه شهری: بخشی از یک شهر بزرگ که مرکز آمار برای آن کد شهری جداگانه در نظر گرفته است. در فایل مرکز آمار همراه شهرها ثبت می‌شود؛ در این مخزن DivisionType = 7 دارد و والدش شهر است.
